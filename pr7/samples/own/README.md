# Власні зразки

`rahunok-04-rotate-noise.jpg` — додатковий синтетично погіршений варіант;
його очікувані поля успадковуються з `clean/rahunok-04.png` у manifest.

Для виконання якісної частини оцінювання додайте сюди справжнє фото
рахунку, надрукованого або відкритого на екрані, внесіть його назву й
джерело з правильними полями у `manifest.json` та зафіксуйте результати.
Не додавайте рахунки з персональними чи платіжними даними без дозволу.
