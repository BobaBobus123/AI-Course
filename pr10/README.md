# ПР10. Надійний AI-сервіс і AI UX

FastAPI-застосунок для створення чернеток відповідей клієнтам. ПР10 демонструє абстракцію AI-провайдера, контрольовані повтори та таймаути, обмеження частоти й паралельності, фонову генерацію з SSE, скасування та fallback.

## Запуск демонстрації без API-ключа

Потрібен Python 3.10 або новіший. У Windows PowerShell:

```powershell
cd pr10
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
python -m uvicorn app.main:app --reload
```

Відкрийте <http://127.0.0.1:8000>. За замовчуванням `.env.example` обирає `LLM_PROVIDER=mock`: застосунок запускається без мережевого доступу до AI-провайдера й без ключа, а текст береться з демонстраційних прикладів у `pr10/samples/requests.json`.

Для macOS/Linux використайте `python3`, активуйте середовище командою `source .venv/bin/activate`, скопіюйте файл командою `cp .env.example .env`, після чого запустіть ту саму команду Uvicorn.

## Справжній Gemini API (необов'язково)

Для генерації відповідей справжньою моделлю потрібні власний API-ключ і доступна квота Google AI Studio:

1. Створіть ключ у [Google AI Studio](https://aistudio.google.com/api-keys).
2. У локальному `pr10/.env` встановіть `LLM_PROVIDER=openai` і запишіть ключ у `LLM_API_KEY`.
3. Перевірте, що `LLM_MODEL` — доступна вашому проєкту модель; для резервного демонстраційного режиму залиште `LLM_FALLBACK=mock`.
4. Перезапустіть сервер.

API-ключ не потрібен для запуску mock-режиму. Не додавайте `.env` до Git і не надсилайте ключ у чат. Реальний API може відповідати 429/503 через квоту чи навантаження; у такому разі застосунок обмежено повторює запит, а потім переходить на mock, якщо fallback увімкнено. Результат із позначкою mock/fallback — демонстраційний, не згенерований реальною моделлю.

### Якщо Gemini API повертає 403

Чат у Google AI Studio та Gemini API — різні способи доступу: чат може відповідати, навіть якщо API для повʼязаного з ключем проєкту недоступний. Повідомлення `The Gemini API free tier is not available for this project` означає, що для цього проєкту Google вимагає платний рівень. Створення іншого ключа або вхід в інший акаунт самі собою не вмикають доступ — перевірте проєкт, до якого привʼязаний ключ.

Підключати білінг необовʼязково для цієї практичної: mock-режим працює без ключа, квоти й оплати та дозволяє показати фонову задачу, SSE, повтори й fallback. Якщо потрібна саме справжня генерація Gemini, власник проєкту може налаштувати білінг у [Google AI Studio](https://aistudio.google.com/billing). За поточною інструкцією Google перехід на платний рівень вимагає платіжного акаунта й мінімальної передоплати $5 або еквівалента; перевірте актуальні умови, ліміти та можливі витрати перед підтвердженням. Платний доступ не гарантує відсутності 429/503.

## Що перевірити в інтерфейсі

- Чернетка створюється у фоні: `POST /api/drafts` повертає HTTP 202.
- Текст і статуси надходять подіями Server-Sent Events.
- Скасування не дозволяє задачі завершитися зі статусом `done`.
- Тимчасові помилки провайдера спричиняють обмежені повтори з backoff.
- Після невдалих спроб використовується налаштований fallback.
- Rate limit віддає HTTP 429 і заголовок `Retry-After`.
- Неповна відповідь не позначається готовою; числові твердження перевіряються щодо наданих фактів.

Інші API: `/api/health`, `/api/requests`, `/api/drafts`, `/api/drafts/{id}`, `/api/drafts/{id}/events`, `/api/drafts/{id}/cancel`.

## Структура проєкту

- `pr10/app/providers/` — контракт, OpenAI-сумісний і mock-провайдери.
- `pr10/app/gateway.py` — таймаути, спроби, semaphore і fallback.
- `pr10/app/jobs.py` — фонові задачі, стан чернеток і SSE-події.
- `pr10/app/main.py` — FastAPI-ендпоінти та стандартизовані помилки.
- `pr10/app/limits.py` — обмеження частоти запитів клієнта.
- `pr10/app/drafting.py` — запит до моделі та перевірки чернетки.
- `pr10/samples/` — приклади звернень і відповідей для mock.

Стан задач і ліміти зберігаються в пам'яті процесу; це навчальна демонстрація, не production-сховище.
