## 2. Аналіз виявлених помилок моделі
1. **Пропуск об'єкта (False Negative):**
   - На фото `Кот с наушниками.jpg` через нетиповий аксесуар (навушники) confidence моделі становить `< 0.50`. При порозі `0.25` об'єкти знаходяться (`2`), але вже при `0.50` кіт повністю пропускається (`0`).
   - На фото `Хаски.jpg` (`conf = 0.74`) та `Леопард.jpg` (`conf = 0.71`) об'єкти успішно детектуються при порозі `0.50`, але відсікаються при піднятті порога до `0.75`.
2. **Неправильний клас (Misclassification):**
   - На фото `Леопард.jpg` зображено леопарда, проте в базовому наборі Microsoft COCO (80 класів) такого класу немає. Модель класифікує тварину як домашнього кота — `cat` із впевненістю `0.71`.
3. **Хибні спрацювання та дублі (False Positives / Duplicates):**
   - На `Кот с наушниками.jpg` при низькому порозі `0.25` детектор повертає `2` об'єкти замість одного кота (додаткове спрацювання на елементи навушників/фону).

## 3. Висновок щодо вибору порога впевненості (Confidence Threshold)
- **Низький поріг (`0.25`)** дозволяє не пропустити складні або частково перекриті об'єкти (як кіт у навушниках), проте дає зайві спрацювання.
- **Середній поріг (`0.50`)** відсікає шум, але може пропускати нестандартні ракурси.
- **Високий поріг (`0.75`)** залишає лише еталонні об'єкти (`Жираф.jpg` з `0.91` та `Самолеты.jpg`), але відсікає навіть правильні передбачення з упевненістю `0.71–0.74` (`Хаски.jpg`).
